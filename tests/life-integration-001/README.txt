검토용 / 정식게임 또는 미술 최종승인 아님

1. ui.html : 독립 UI 시범 / 0~6 수동단계 / 충격 / 회복 / 움직임 / 효과 설정
2. compare.html : 동일 실제 계약화면 4상태 정적 HTML 비교

4. audit.html : 15항목 재검증
5. evidence/ : 기능 QA/검사코드

ZIP 압축을 풀고 ui.html 또는 game/index.html을 브라우저에서 열어 확인할 수 있습니다.
외부 의존성 없이 같은 폴더의 상대경로 자산을 사용합니다.
file:// 환경의 저장 동작은 브라우저마다 다를 수 있습니다.
브라우저 동작/모바일 렌더 QA 미완료 / 서버에서 실행하는 경우 같은 폴더를 문서 루트로 사용합니다.
Pages 게시가 자동 승인 검토에 차단되어 실제 플레이 URL과 HTTP200 검증은 아직 없습니다.
기존 정식 게임/저장 데이터와 통합하지 않았습니다.
정적 PDF/JPG는 검토용 설계 그림이며 브라우저 캡처가 아닙니다. 실제 CSS 렌더와 차이가 있을 수 있습니다.
